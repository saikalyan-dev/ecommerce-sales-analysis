# E-Commerce Sales Analytics Project

## Dataset
Brazilian E-Commerce Public Dataset by Olist:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Overview
This project analyzes e-commerce sales data using SQL and MySQL.

## Dataset
Brazilian E-Commerce Public Dataset by Olist

## SQL Concepts Used
- JOINs
- GROUP BY
- Aggregations
- Subqueries
- Date Functions

## KPIs Analyzed
- Total Revenue
- Average Order Value
- Monthly Revenue Trends
- Top Customers
- Product Category Performance

## Tools Used
- MySQL
- MySQL Workbench

## Key Insights
- November 2017 generated the highest revenue.
- Some product categories generated significantly higher revenue.
- Revenue trends varied month by month.
